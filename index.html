🎨 O que é CSS?

CSS (Cascading Style Sheets) é o que deixa seu site bonito! Ele controla cores, tamanhos, posições e animações.

/* Sintaxe básica */
seletor {
  propriedade: valor;
}

🎯 Seletores

/* Por tag */
p { color: blue; }

/* Por classe (.) */
.destaque { background: yellow; }

/* Por ID (#) */
#titulo { font-size: 30px; }

/* Combinados */
div p { }        /* p dentro de div */
h1, h2 { }       /* h1 OU h2 */
a:hover { }      /* ao passar o mouse */
input:focus { }  /* quando clicado */
li:first-child { } /* primeiro filho */

📦 Box Model

Tudo em CSS é uma "caixa" com: conteúdo, padding, borda e margem.

.caixa {
  width: 200px;          /* largura */
  height: 100px;         /* altura */
  padding: 20px;         /* espaço interno */
  border: 2px solid black; /* borda */
  margin: 10px;          /* espaço externo */
}

🌈 Cores e Fundos

.exemplo {
  color: red;                    /* cor do texto */
  color: #ff6b6b;                /* hexadecimal */
  color: rgb(255, 107, 107);      /* RGB */
  color: rgba(255, 107, 107, 0.5); /* com transparência */
  
  background: blue;
  background: linear-gradient(90deg, red, yellow);
  background: radial-gradient(circle, blue, black);
  background-image: url('foto.jpg');
}

💪 Flexbox (Layout moderno!)

Flexbox organiza itens em linha ou coluna de forma flexível.

.container {
  display: flex;
  justify-content: center;   /* eixo horizontal */
  align-items: center;       /* eixo vertical */
  flex-direction: row;       /* row | column */
  gap: 20px;                 /* espaço entre itens */
  flex-wrap: wrap;           /* quebra linha */
}

.item {
  flex: 1;                   /* ocupa espaço igual */
}

📱 Responsividade (@media)

Adapta o site para celular, tablet e desktop!

/* Tela menor que 768px (celular) */
@media (max-width: 768px) {
  .container {
    flex-direction: column;
  }
}

/* Tela maior que 1024px (desktop) */
@media (min-width: 1024px) {
  .container {
    max-width: 1200px;
  }
}

⚙️ O que é JavaScript?

JavaScript dá vida ao site! Ele faz as coisas acontecerem: cliques, animações, cálculos, etc.

// Exibir mensagem
alert("Olá, mundo!");
console.log("Aparece no console");

📦 Variáveis

let nome = "Ana";       // pode mudar
const idade = 25;       // constante, não muda
var antigo = "evite";   // antigo, prefira let/const

// Tipos de dados
let texto = "Olá";        // string
let numero = 42;          // number
let decimal = 3.14;       // number
let ativo = true;         // boolean
let vazio = null;         // nulo
let indefinido;             // undefined

📝 Template Literals

Use crases (`) para misturar texto e variáveis facilmente!

let nome = "João";
let idade = 20;

// Jeito antigo
console.log("Olá, " + nome + ", você tem " + idade);

// Jeito moderno (template literal)
console.log(`Olá, ${nome}, você tem ${idade} anos!`);

🔧 Funções

// Função tradicional
function saudar(nome) {
  return `Olá, ${nome}!`;
}

// Arrow function (moderna!)
const saudar2 = (nome) => `Olá, ${nome}!`;

// Função com valor padrão
const somar = (a, b = 0) => a + b;

console.log(saudar("Maria"));  // Olá, Maria!
console.log(somar(5, 3));      // 8

📋 Arrays (Listas)

const frutas = ["maçã", "banana", "uva"];

console.log(frutas[0]);       // maçã
console.log(frutas.length);   // 3

frutas.push("laranja");      // adiciona no final
frutas.pop();                // remove o último

// Métodos PODEROSOS!
const numeros = [1, 2, 3, 4, 5];

// map: transforma cada item
const dobro = numeros.map(n => n * 2);
// [2, 4, 6, 8, 10]

// filter: filtra itens
const pares = numeros.filter(n => n % 2 === 0);
// [2, 4]

// reduce: reduz a um valor
const soma = numeros.reduce((acc, n) => acc + n, 0);
// 15

// find: encontra o primeiro
const maior3 = numeros.find(n => n > 3);
// 4

🗂️ Objetos

const pessoa = {
  nome: "Ana",
  idade: 25,
  cidade: "SP",
  saudar() {
    return `Oi, sou ${this.nome}!`;
  }
};

console.log(pessoa.nome);       // Ana
console.log(pessoa["idade"]);   // 25
console.log(pessoa.saudar());   // Oi, sou Ana!

// Destructuring (desestruturar)
const { nome, idade } = pessoa;
console.log(nome);  // Ana

🔀 Condicionais e Loops

// if / else
const idade = 18;
if (idade >= 18) {
  console.log("Maior de idade");
} else {
  console.log("Menor");
}

// Operador ternário (if curto)
const status = idade >= 18 ? "adulto" : "jovem";

// for loop
for (let i = 0; i < 5; i++) {
  console.log(i);
}

// for...of (para arrays)
const frutas = ["maçã", "banana"];
for (const fruta of frutas) {
  console.log(fruta);
}

🎯 DOM (Manipular a página!)

O DOM é a árvore de elementos HTML. Com JS você pode mudar tudo!

// Selecionar elementos
const titulo = document.getElementById("titulo");
const btn = document.querySelector(".botao");
const itens = document.querySelectorAll("li");

// Mudar conteúdo
titulo.textContent = "Novo título";
titulo.innerHTML = "<em>Com</em> HTML";

// Mudar estilo
titulo.style.color = "red";
titulo.style.fontSize = "30px";

// Mudar classe
titulo.classList.add("ativo");
titulo.classList.remove("escondido");
titulo.classList.toggle("ativo");

// Criar elemento
const novo = document.createElement("p");
novo.textContent = "Novo parágrafo";
document.body.appendChild(novo);

💾 LocalStorage (Salvar dados)

Salve dados no navegador do usuário (persiste mesmo fechando a página).

// Salvar
localStorage.setItem("nome", "Ana");
localStorage.setItem("usuario", JSON.stringify({nome: "Ana", idade: 25}));

// Ler
const nome = localStorage.getItem("nome");
const user = JSON.parse(localStorage.getItem("usuario"));

// Remover
localStorage.removeItem("nome");
localStorage.clear();  // limpa tudo

🌐 Fetch API (Buscar dados da internet)

// Buscar dados de uma API
async function buscarUsuarios() {
  try {
    const resposta = await fetch("https://api.example.com/users");
    const dados = await resposta.json();
    console.log(dados);
  } catch (erro) {
    console.error("Erro:", erro);
  }
}

buscarUsuarios();

🚀 Projeto 2: Lista de Tarefas

<input id="tarefa" placeholder="Nova tarefa">
<button onclick="adicionar()">Adicionar</button>
<ul id="lista"></ul>

<script>
  function adicionar() {
    const input = document.getElementById("tarefa");
    const lista = document.getElementById("lista");
    if (input.value) {
      const li = document.createElement("li");
      li.textContent = input.value;
      li.onclick = () => li.remove();
      lista.appendChild(li);
      input.value = "";
    }
  }
</script>
